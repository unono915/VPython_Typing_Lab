# VPython Typing Lab

**VPython 코드에 실제로 나오는 단어와 기호로 영타를 연습하는 페이지.**
설치 없음 · 로그인 없음 · 인터넷 없어도 동작.

## 왜 만들었나

고등학교 1학년 「생성형 AI와 메이커 실습」 과목은 17주 내내 학생이 코드를 직접 친다.
그런데 실습 시간을 잡아먹는 건 개념이 아니라 **타이핑**이다. 특히 기호에서 막힌다.

- `(` `)` 를 찾느라 손이 멈춘다
- `_` 와 `-` 를 혼동한다
- `.` `,` `=` 오타를 내고 원인을 못 찾는다

일반 타자 연습 사이트는 한글 산문을 치게 한다. 그래서 교과 어휘로 직접 만들었다.

## 기능

| | |

| **업적 8종** | 무결점 · 콤보 100 · 정밀 · 삼단 완주 … |

| **한/영 · CapsLock 점검** | 한글 상태나 CapsLock 이면 경고를 띄우고 **채점도 타이머도 시작하지 않는다** |
| **본인 확인** | 공용 PC 에서 앞사람 이름으로 기록이 넘어가지 않도록, 새로 열 때마다 한 번 확인받는다 |
| **교사용 대시보드** | 학생별 요약 · 필터 · 정렬 · CSV · **명렬표 대조(누가 아직 안 했나)** · 기록 삭제 |

## 학생 기록 수집 (선택)

`assets/js/config.js` 의 `sync: true` 이면 학생이 한 판 끝낼 때마다 기록이 서버로 전달되고,
교사는 `teacher.html` 에서 확인한다. `sync: false` 로 두면 완전한 오프라인 모드가 된다.

**보안 구조** — 공개 키가 노출돼도 안전하도록 DB 에 규칙을 걸어 두었다.

| 역할 | INSERT | SELECT | UPDATE | DELETE |
|---|---|---|---|---|
| 학생 (익명) | ✅ | ❌ | ❌ | ❌ |
| 로그인했지만 **미등록** 계정 | ❌ | ❌ | ❌ | ❌ |
| 교사 (`public.teachers` 등록) | ❌ | ✅ | ❌ | ✅ |

학생은 **자기 기록조차 다시 읽을 수 없다.** 남의 기록을 보거나 점수를 고치는 것도 불가능하다.

> ⚠️ **로그인 자체는 자격이 아니다.** Supabase 프로젝트는 기본적으로 공개 가입이 열려 있고
> 공개 키는 페이지 소스에 노출된다. 그래서 "로그인한 사용자면 누구나 읽기" 로 두면
> **외부인이 스스로 가입해 학생 기록을 전부 볼 수 있다.**
> `public.teachers` 에 등록된 계정만 읽도록 막아 두었다.
값 범위(타수 0~2000, 정확도 0~100 등)는 DB 의 CHECK 제약으로 막혀 있어 클라이언트를 신뢰하지 않는다.

수집 항목은 **반·학번·이름과 연습 결과**뿐이다. 그 외의 개인정보는 저장하지 않는다.

### 교사 계정 만들기 (최초 1회)

**1단계 — 계정 만들기**

1. Supabase 대시보드 → 프로젝트 → **Authentication → Users**
2. **Add user → Create new user**
3. 이메일과 비밀번호를 **직접** 정해 입력하고 **Auto Confirm User** 를 켠 뒤 저장

**2단계 — 조회 권한 주기 (필수)**

계정만 만들면 아무것도 보이지 않는다. SQL Editor 에서 이메일만 바꿔 실행한다.

```sql
insert into public.teachers (user_id, email)
select id, email from auth.users
where email = '교사@이메일'
on conflict (user_id) do nothing;
```

**권장 — 외부인 가입 막기**

대시보드 → **Authentication → Sign In / Providers → Email** 에서
**Allow new users to sign up** 을 끈다. 2단계를 했다면 가입해도 아무것도 못 보지만,
아예 막아 두는 편이 낫다. 같은 화면에서 **Leaked password protection** 도 켜 두면 좋다.

비밀번호는 선생님만 아셔야 하므로 반드시 직접 정하세요.

## 수업에서 쓰는 법

1. 링크를 학생에게 준다. 끝.
2. 이름을 입력하게 하면 결과 화면에 이름이 찍혀서 **캡처를 걷을 때 누구 건지 보인다.**
3. 한 판이 1~2분이다. 20분 수업이면 LEVEL 1 한 판 → 남은 시간에 2·3단계.
5. 수업 끝에 대시보드에서 **명렬표 붙여넣기** → 아직 안 한 학생이 바로 나온다.
4. 결과 화면의 **"가장 많이 틀린 문자"** 를 보여주며 한마디 해주면 효과가 크다.
   → *"네가 제일 많이 틀린 건 알파벳이 아니라 괄호야."*

단어 뜻은 설명하지 않아도 된다. 오늘은 손가락만 익히는 날이고,
다음 시간에 `sphere` 가 나오면 *"어제 쳤던 거네"* 하고 알아본다.

## 문제 세트 고치기

**`assets/js/data.js` 한 파일만 고치면 된다.** 다른 파일은 손댈 필요 없다.

```js
{
  id: 'words',
  name: '낱말',
  hint: 'sphere · vector · rate',
  count: 12,                    // 한 판에 출제할 개수
  par: [260, 200, 150, 100],    // 등급 기준 타수 [S, A, B, C]
  items: [
    'sphere',                   // ← 한 줄이 문제 하나
    'vector',
    ...
  ]
}
```

작은따옴표가 들어간 문자열은 큰따옴표로 감싼다 — `"scene.title = 'hi'"`.

레벨을 통째로 추가하려면 `levels` 배열에 같은 모양의 객체를 하나 더 넣으면 된다.
(예: ESP32 단원용 `digitalWrite`, `analogRead`, `pinMode` 세트)

## 로컬에서 열기

빌드 도구가 필요 없다.

```bash
git clone https://github.com/unono915/VPython_Typing_Lab.git
```

`index.html` 을 브라우저로 열면 끝. 인터넷 없이도 동작한다.
실습실 인터넷이 불안하면 이 폴더를 USB로 옮겨 써도 된다.

**HTML 한 장으로 만들기** (USB 배포용)

```bash
npm run build      # → dist/VPython_Typing_Lab_offline.html (약 41KB)
```

CSS·JS가 전부 인라인된 파일 하나가 나온다. 이것만 있으면 된다.

> ⚠️ `file://` 로 열면 브라우저가 `localStorage` 를 막는 경우가 있다.
> 그러면 **기록과 업적이 저장되지 않는다.** (연습 자체는 정상 동작하고, 결과 화면도 그대로 나온다.)
> 기록을 남기려면 배포된 주소로 접속하거나, 로컬 웹서버로 띄운다 — 예: `npx serve`

```bash

npm run test:edge     # 39개 — 공용 PC · 손상된 저장소 · 전부 건너뛰기 등 엣지 케이스
npm run test:teacher  # 49개 — 로그인 · 집계 · 필터 · 정렬 · 명렬표 · 삭제
```

jsdom 기반 헤드리스 테스트다. **사이트 자체에는 의존성이 없고**, jsdom 은 테스트 전용이다.

## 배포

**GitHub Pages · Deploy from a branch.** 빌드 단계가 없으므로 Actions 워크플로를 두지 않는다.

저장소 **Settings → Pages** 에서 최초 1회만 설정한다.

| 항목 | 값 |
|---|---|
| Source | Deploy from a branch |
| Branch | `main` |
| Folder | `/ (root)` |

이후 `main` 에 푸시하면 1~2분 안에 반영된다.
