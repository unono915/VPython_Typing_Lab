학생 기록 대시보드

학생 기록은 로그인한 교사만 볼 수 있습니다. 학생은 기록을 남기기만 할 뿐, 자기 기록조차 다시 읽을 수 없습니다.

처음이신가요? 계정 만드는 법
  1. Supabase 대시보드 → 이 프로젝트 → Authentication → Users
  2. Add user → Create new user
  3. 이메일과 비밀번호를 직접 정해서 입력하고, Auto Confirm User 를 켠 뒤 저장
  4. 그 계정으로 이 페이지에서 로그인

비밀번호는 선생님만 아셔야 하므로 직접 정하세요. 계정은 하나면 충분합니다.
